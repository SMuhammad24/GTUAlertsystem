🎓 GTU Alert System Problem & Proposed Solution

⚠️ Problem Statement & Objective

Analyzing why students miss critical deadlines and how automation solves it.

❌

The Real-World Problems

  • Missed Deadlines & Heavy Penalties: Students frequently miss exam form deadlines, remedial registrations, and fee payment windows due to lack of timely alerts.
  • High Friction in Daily Checking: Visiting gtu.ac.in multiple times daily on slow networks is cumbersome and easily forgotten.
  • Information Overload: GTU releases 10-20 mixed circulars daily. Finding branch-relevant notices requires tedious manual filtering.
  • Faculty & CR Burden: Class coordinators must manually download and forward PDFs in various WhatsApp groups.
✅

The Automated Solution

  • Instant Push Notification: Scans GTU public board every 15 minutes and immediately broadcasts new circulars.
  • Direct 1-Click PDF Link: Attached direct official GTU download link so students can view the document with one click.
  • Priority Categorization: Distinguishes critical notices (🚨 Fee/Penalty, 📝 Timetables, 📊 Results) with clear visual icons.
  • 24/7 Zero Maintenance: Runs automatically on the cloud (GitHub Actions / Daemon) with 0 server hosting cost.
🎯

Core Project Objectives

Zero Information Delay: Reduce notification lag from hours/days down to minutes.
Zero Student Data Risk: Absolute safety with zero credentials or personal records accessed.
Zero Repeat Spam: SQLite deduplication engine guarantees each circular is posted exactly once.
🗣️ Presenter Talking Point: "Sir/Ma'am, students often face late exam fee penalties because manual checking is inconsistent. Our bot eliminates this friction by pushing notices directly to student groups the moment GTU uploads them."

🛡️ Data Privacy & Ethical Compliance

Explicit guarantee regarding zero student data collection and server safety.

🔒 100% Zero Student Data Guarantee

This system is purely a Public Notice Reader. It never interacts with any student database, marksheet system, or private college portal. It only reads what GTU has published publicly on the world wide web for all students.

Area System Policy Reasoning & Justification
Student Credentials ZERO ACCESS No logins / IDs used Does not ask for Enrolment No, Passwords, Names, or DOB.
Internal Portals BLOCKED Never accessed Strictly ignores student.gtu.ac.in, ERP portals, and CAPTCHAs.
Data Extracted PUBLIC ONLY Circular Title, Date & PDF URL Only reads the open public table at gtu.ac.in/Circular.aspx.
University Server Load RATE LIMITED 15-min Intervals Lightweight HTTP requests with standard headers; 0% risk of server overload.
Student Privacy on Telegram PROTECTED Group / Channel Broadcast Students receive updates without having to share their phone numbers.
💡

Why This Architecture Was Chosen (Technical Reasoning)

Why Telegram Bot API?

Provides official webhooks, high reliability, free tier without limits, and rich HTML formatting with direct links.

Why SQLite Deduplication?

Lightweight zero-dependency database keeps a permanent log of dispatched circular IDs to prevent repetitive spam.

Execution Workflow Pipeline

Step 1 • Public Web Scraper
Fetch Official Circular Table

Analyze Keywords & Urgency
Detects Fee deadlines, Exam schedules, Result alerts, and Admission notices.

Filter Duplicate Records

Broadcast Rich Formatted Alert
Formats message with category badge, title, date, and 1-click official PDF link.

Top Faculty Viva Questions & Defenses

Q1: Will this scraper overload or crash GTU servers?

Defense: No, Sir/Ma'am. It only performs 1 standard HTTP GET request every 15 minutes with respectful rate-limiting, which consumes less traffic than a single browser page refresh.

Q2: Is there any risk of student confidential data leak?

Defense: No. The project never interacts with user databases, enrolment portals, or logins. It purely acts as a broadcaster for already public announcements.

Q3: What happens if the host machine goes offline?

Defense: The bot is integrated with GitHub Actions cloud workflows, enabling 24/7 autonomous monitoring on GitHub's secure cloud servers for free.
